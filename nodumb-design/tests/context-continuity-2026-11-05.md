# Проверка сохранения контекста между поверхностями — 2026-11-05

## Что проверялось

Нужно было выяснить, закрывает ли новое правило реальный пробел
`nodumb-design`, не заставляя добавлять сводку на каждый экран. Сравнивались
текущий скилл, полный текст PR #1 и сокращённая версия.

Критерии успеха:

- зависимый шаг сохраняет решение, меняющее смысл, правила или последствия;
- самостоятельная поверхность не получает лишний контекст;
- выбирается самое лёгкое достаточное представление;
- изменение выбора не скрывает потерю введённых данных;
- неизвестный контракт не додумывается внутри дизайн-правила.

## Результат

Полная и сокращённая версии принимают одинаковые решения в проверенных
сценариях. Сокращённая версия сохраняет развилку, четыре уровня представления,
изменение выбора и маршрутизацию в соседние скиллы без повторения одних критериев
в нескольких разделах.

Структурная проверка выполнена `quick_validate.py`; также проверены локальная
ссылка и `git diff --check`. Семантический прогон выполнен по сценариям вручную;
отдельный слепой прогон другой моделью не проводился.
